사내 운영 자동화 · 2026.09 · 운영 중

자동화 통합 관리자

회사 콘텐츠 운영을 통째로 자동화한 웹 관리자. 로그인해서 캡처하고, GPT로 글을 쓰고, 6개 채널에 게시·발송합니다.

사내용 · 화면만 공개
문제

자동화 3개가 폴더 3곳과 Windows 스케줄러 3개에 흩어져 서로 충돌했고, PC가 꺼지면 멈췼습니다.

기획 판단

한 화면에서 스케줄·실행·이력·로그인 세션을 관리. 직렬 실행 큐, 테스트 모드와 스케줄러 전역 스위치, 거래일·휴장일 판정, 같은 날 재실행 시 성공분 건너뛰기.

만든 것

작업 10종. Playwright로 아임차트M·네이버·AI데이터맵에 로그인해 캡처하고, OpenAI로 브리핑을 쓰고, 카페·프리미엄콘텐츠·GPT-Report·이벤트 캘린더에 게시, 텔레그램·앱 푸시로 발송. Docker로 Railway 상시 운영, 2차 인증은 noVNC 원격 화면으로.

결과

11일 만에 폴더 4개를 하나로 합쳤고, 매 거래일 06:30부터 09:10까지 사람 손 없이 돌아갑니다. 재현 불가한 PC·MTS 푸시는 모바일 개발자용 FCM 규격서로 넘겼습니다.

Stockr

종목명 하나를 넣으면 시세·차트·지표를 붙여 대화로 분석해 주는 서비스. 아임차트 회원용 AI 상담 창구입니다.

stockr.iamchart.co.kr ↗
문제

개인투자자가 범용 AI에 종목을 물으면 시세도 차트도 없는 일반론만 돌아옵니다.

기획 판단

입력은 종목명 하나로 줄이고, 답은 투자 성향(공격·중립·안정), 금액, 기간, 목적에 맞춰 바꿉니다. 유사투자자문 규정상 금지되는 수익률·매매 권유 표현은 프롬프트 층에서 막았습니다.

만든 것

국내·미국 종목 자동완성, 1M~3Y 차트와 이동평균·RSI, 추천 질문, 대화 이력. 아임차트 패밀리 서비스 11종의 배경지식 프롬프트와 질문 키워드 매핑 규칙.

결과

2026년 7월 1일 출시. 로그인 없이 쓸 수 있고, 회사 서비스 전체의 안내 창구 역할까지 맡고 있습니다.

SellQ Agent

무자본·배대지 셀러가 '오늘 뭘 등록할지'를 감이 아니라 점수로 정하게 하는 AI 작전참모입니다.

sellq-agent.vercel.app ↗
문제

초보 리셀러는 시세도 경쟁도 모른 채 상품을 올립니다. 개발 도중 네이버 오픈API 신규 발급이 끊겨 데이터 소스도 바꿔야 했습니다.

기획 판단

네이버 검색광고 API 하나로 100점 점수화. 수요 25, 검색량 15, 경쟁도 20, 마진 20, 리스크 10, 시즌성 10. 비중은 슬라이더로 사용자가 바꿉니다. 품질이 안 나온 '키워드 발굴'은 폐기하고 시즌 캘린더로 대체했습니다.

만든 것

시즌 캘린더, 상품 검증, AI 상세페이지 생성, 후보 키워드 관리, 이력. 업종 52개 인기 키워드 4.8만 개 화이트리스트. API 키는 서버에 저장하지 않는 구조.

결과

도매꾹·도매매 'AI 직원 만들기' 강의의 실습 도구로 사용. 설치형 exe 패키지도 배포.

이커머스 매출 관리 · 'AI 직원 20명' 커리큘럼의 실동작 모듈

매출관리 AI 직원

총매출이 아니라 취소·반품·광고비·원가를 뺀 뒤 얼마가 남는지를 보여주는 셀러용 매출 화면입니다.

sales-ai-employee.vercel.app ↗
문제

셀러는 플랫폼별 총매출만 보고, 광고를 켠 게 득인지 실인지 끝까지 모릅니다.

기획 판단

순매출 → 광고 효율(ROAS) → 원가 반영 실손익 순서로 화면을 배치. 예측 대신 실측만 씁니다. 품목별로 월 광고 ON/OFF를 표시해 켠 달과 끈 달의 평균 매출을 나란히 비교합니다.

만든 것

쿠팡·네이버 탭과 합산 탭, 파일 업로드, 키워드 칩 검색, 행 단위 수정·삭제, 백업·복원. 함께 만든 CS AI 직원은 신뢰도 50% 이상 자동 답변, 20% 미만 사람 인계 규칙으로 동작합니다.

결과

'Commerce AI Company' 커리큘럼(회사 설립 → AI 직원 채용 → 사규 → 인수인계 → 대시보드)에서 실제로 돌아가는 모듈. 1시간 실습 교육 패키지로 정리.

팀 기획

회사의 세 플랫폼에서 화면과 콘텐츠를 정하고, 프롬프트를 관리하고, 랜딩 페이지를 만들었습니다.

AI 기사 생성 시스템 · 2026.08 ~ · 파일럿

ADAMS

AI Data Assistant Media System. 매 거래일 17,645개 종목의 데이터를 룰 200여 개로 검사해 '주목도' 점수를 매기고, 점수 구간에 맞는 5종 기사(속보·브리핑·기사·심층·전략리포트)를 AI가 씁니다.

  • 기사 유형 체계 확정 프롬프트 11개가 점수축과 룰축으로 겹쳐 있던 문제를 규명해 L1·L2 각 5종으로 정리. 유형별 분량 300~1,500자 규칙.
  • 프롬프트 21종 v2 전량 개정 외부 모델에 자동 주입하는 백테스트를 10여 회 돌려 실패 원인(지표 원값 노출, 반복, 물러서는 어투)을 고쳤고, 룰 이름을 독자 언어로 번역하는 해석표를 만들었습니다.
  • 화면 9종 기획과 프로토타입 카드 보기, 기사 전문, 시장 연계 기사, 주목할 점 찾기, 기사 만들기(PRO 포인트 정책값)까지 구조·문구·정책을 지정. 랜딩 8섹션, 마케팅 플랜, 로그인 썸네일 제작.

  • 콘텐츠 구조 정의 대시보드, GPT-Chart 6종, GPT-Table 5종, 마켓마인드, 이벤트 캘린더의 메뉴 트리와 각 화면이 담을 콘텐츠를 문서로 확정.

  • 콘텐츠 운영 자동화 GPT-Report의 글로벌 모닝지표 브리핑과 이벤트 캘린더의 주간 증시일정은 제가 만든 자동화가 매 거래일 게시합니다.
